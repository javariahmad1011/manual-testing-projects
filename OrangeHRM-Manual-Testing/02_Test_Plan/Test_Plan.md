# Test Plan – OrangeHRM Demo

## 1. Introduction

This Test Plan outlines the testing approach, objectives, scope, resources, schedule, and deliverables for the OrangeHRM Demo application. The goal is to ensure that the application's core functionalities work correctly and provide a reliable user experience.

---

## 2. Objectives

- Verify that all critical functionalities work as expected.
- Validate system behavior for valid and invalid inputs.
- Identify functional and UI defects.
- Ensure business requirements are met.

---

## 3. Scope

### In Scope

- Login
- Dashboard
- Admin
- PIM
- Leave
- Recruitment
- My Info
- Directory

### Out of Scope

- Performance Testing
- Security Testing
- Load Testing
- Mobile Testing
- Database Validation

---

## 4. Test Types

- Functional Testing
- UI Testing
- Smoke Testing
- Regression Testing
- Negative Testing

---

## 5. Test Environment

| Item | Details |
|------|---------|
| Application | OrangeHRM Demo |
| URL | https://opensource-demo.orangehrmlive.com/ |
| Browser | Google Chrome (Latest) |
| Operating System | macOS |
| Testing Type | Manual Testing |

---

## 6. Entry Criteria

Testing will begin when:

- Application is accessible.
- Test environment is available.
- Test data is prepared.
- Requirements are understood.

---

## 7. Exit Criteria

Testing will be completed when:

- All planned test cases have been executed.
- Critical and High severity defects are resolved or documented.
- Test Summary Report is prepared.

---

## 8. Test Deliverables

- Requirement Analysis
- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Test Execution Report
- Test Summary Report

---

## 9. Risks

- Demo application downtime
- Changes to demo data
- Internet connectivity issues

---

## 10. Assumptions

- Stable internet connection
- Demo application remains available
- Test accounts remain functional

---

## 11. Roles & Responsibilities

|------|----------------|
| QA Engineer | Requirement analysis, test planning, test case design, execution, bug reporting, and reporting |
