## Summary

ESS access to protected Job and/or Salary information did not satisfy the expected read-only permission behavior during execution of `TC-MYI-004`.

## Preconditions

- A valid ESS user account is available.
- The ESS user is authenticated.
- **My Info** is accessible.

## Steps to Reproduce

1. Log in as an ESS user.
2. Open **My Info**.
3. Navigate to the available **Job** and/or **Salary** area.
4. Inspect whether protected employment fields expose editable controls.
5. Where editing is permitted by the UI, attempt to modify a protected field.
6. Observe whether the application blocks or persists the change.

## Actual Result

The historical execution was recorded as **Fail** because ESS access did not satisfy the expected read-only/restricted permission behavior.

The source execution did not retain which specific controls were editable or whether a change was successfully persisted. Those details must be confirmed during reproduction.

## Expected Result

Protected Job and Salary information should remain read-only or otherwise restricted for the ESS role according to the test baseline.

## Business / User Impact

If an ESS user can modify protected employment or compensation-related information, authorization controls may be insufficient. This could affect data integrity and expose sensitive HR operations to an unauthorized role.

Because detailed historical evidence is missing, the exact scope must be confirmed before engineering triage.
