## Summary

The password reset response recorded for an unknown username did not satisfy the expected account-privacy behavior in `TC-FGP-003`.

## Preconditions

- OrangeHRM Demo is reachable.
- The **Forgot Password / Reset Password** page is open.
- A deliberately unregistered username is available.

## Steps to Reproduce

1. Navigate to the OrangeHRM login page.
2. Select **Forgot your password?**
3. Enter an unregistered username such as `invaliduser123`.
4. Submit the reset request.
5. Record the exact response shown to the user.

## Actual Result

The historical execution was recorded as **Fail** because the response for the unregistered username did not satisfy the expected privacy-preserving behavior.

The exact response text was not retained in the source evidence and must be captured during reproduction before final security triage.

## Expected Result

The application should provide an appropriate generic response that does not disclose whether the supplied username exists.

## Business / User Impact

A reset response that reveals whether an account exists can support username enumeration and reduce account privacy. Because the exact historical message was not retained, the security impact must be confirmed through controlled reproduction before final classification.

## Affected Coverage

- Regression Test Suite — included in full regression coverage
