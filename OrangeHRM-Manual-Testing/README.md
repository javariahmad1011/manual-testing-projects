# OrangeHRM Manual Testing Project

## Overview

This repository contains a complete manual testing project for the OrangeHRM Demo application.

The objective of this project is to demonstrate the complete Software Testing Life Cycle (STLC), including:

- Requirement Analysis
- Test Planning
- Test Scenario Design
- Test Case Design
- Test Execution
- Bug Reporting
- Test Summary Report
