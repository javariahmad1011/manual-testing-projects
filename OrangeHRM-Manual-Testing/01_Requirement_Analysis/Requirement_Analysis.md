# Requirement Analysis – OrangeHRM Demo

## Project Overview

OrangeHRM is a Human Resource Management System (HRMS) that helps organizations manage employee information, recruitment, leave, performance, and other HR-related activities.

This project focuses on validating the core functionalities of the OrangeHRM Demo application through manual testing.

---

## Application Details

- **Application Name:** OrangeHRM Demo
- **Application Type:** Web Application
- **URL:** https://opensource-demo.orangehrmlive.com/
- **Testing Type:** Manual Testing

---

## Scope of Testing

The following modules are included in this project:

- Login
- Dashboard
- Admin
- PIM (Personnel Information Management)
- Leave
- Recruitment
- My Info
- Directory

---

## Features to be Tested

### Login
- Valid login
- Invalid login
- Required field validation
- Forgot Password

### Dashboard
- Dashboard widgets
- Navigation
- Quick Launch options

### Admin
- Search User
- Add User
- Edit User
- Delete User

### PIM
- Add Employee
- Edit Employee
- Delete Employee
- Search Employee

### Leave
- Apply Leave
- Assign Leave
- Leave List

### Recruitment
- Add Candidate
- Search Candidate
- Delete Candidate

### My Info
- Update Personal Details
- Upload Profile Photo

### Directory
- Search Employee
- Reset Search

---

## Out of Scope

- Performance Testing
- Security Testing
- Compatibility Testing
- Mobile Application Testing
- Database Validation

---

## Assumptions

- The demo application is available throughout testing.
- Test data is available.
- Internet connection is stable.
